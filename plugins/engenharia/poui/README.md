# Plugin Eng-VeD - Angular + PO UI

Crie projetos **Angular + PO UI** com mais velocidade e opere **Harness, contexto e automações** com mais controle no ecossistema **TOTVS/Protheus**.

A **Extension Eng-VeD** transforma o VS Code em uma esteira guiada com duas frentes complementares: uma para acelerar a criação e evolução de projetos PO UI, outra para sincronizar contexto, agentes e artefatos rastreados com menos atrito operacional.

### PO UI e Projeto

Esta é a frente voltada para quem precisa sair mais rápido do zero até um projeto utilizável em Angular + PO UI dentro do contexto TOTVS.

- Geração guiada de projeto com base padronizada.

### Harness e Contexto

Esta é a frente mais geral da extensão, voltada para sincronizar contexto oficial, agentes, skills, MCPs e outros artefatos rastreados no workspace.

- Materialização rastreada de `mcps`, `skills`, `agents`, `instructions` e `hooks`.
- Atualização controlada com confirmação quando há mudança local.
- Abertura de notas de release para comunicar, em linguagem simples, o que foi entregue ao criar ou atualizar o Harness.
- Menos drift entre workspaces e menos edição manual de arquivos sensíveis.

### Valor para PO UI

- **Acelera o bootstrap do projeto** com geração guiada de estrutura Angular + PO UI.
- **Reduz retrabalho do time** ao centralizar templates e uma base inicial mais previsível.

### Valor para Harness e Contexto

- **Padroniza contexto e automações** com Harness para materializar `mcps`, `skills`, `agents`, `instructions` e `hooks` de forma rastreada.
- **Reduz retrabalho operacional** ao centralizar contexto oficial e fluxo de atualização.
- **Abre um canal claro de comunicação** com release notes amigáveis sempre que o Harness entrega ou atualiza assets padrão.
- **Prepara o workspace para IA aplicada ao produto** com agentes, regras e contexto local já organizados.

## O Que Você Ganha na Prática

### Ganhos na frente Harness

- Menos divergência entre workspaces de pessoas diferentes.
- Menos edição manual de arquivos de contexto sensíveis.
- Mais clareza sobre o que mudou, com notas de release abertas no editor após o fluxo de Harness.
- Mais previsibilidade para criar, atualizar e remover artefatos de automação.
